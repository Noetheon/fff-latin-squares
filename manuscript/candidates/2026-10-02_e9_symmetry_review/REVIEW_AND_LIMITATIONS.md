# Critical Review and Limits

## Analytic Review

The changed statement has a complete written proof, not just an enumeration.
The two-triple support partition is exhaustive: one shared partition and nine
mixed partitions, each with four orientations. The centralizing rotations are
transitive on the latter nine. Both composition direction and all four displayed
products were checked against the independently written finite control.

The quotient argument uses an **actual autotopy**, not just compatible orbit
counts. Normality of the order-three subgroup fixes the entire selected row
orbit. Relative maps commute with that subgroup; quotient cycles lift to
lengths `ell` or `3*ell`. Row-F rules out quotient fixed points, so the quotient
is a Latin **rectangle**, not an unjustified full FFF square. The global fixed-row
count is handled separately, using two orbit bijections and divisibility by
three. FFF parastrophy supplies the other coordinate placements; row-F alone
was not claimed parastrophy-invariant.

The displayed mixed-factor rectangle is a countercontrol to the stronger but
false permutation assertion. It is not a Latin18 table. The theorem does not
decide the mixed or free action cases, or show that any FFF18 must have odd
symmetry. No action-type census or proof of unrestricted nonexistence is added.

## Reproducibility and Provenance

Only the proof's standalone independent finite-control script and its reference
result were copied from the accepted source package, byte-for-byte. The complete
public proof is an edited presentation of the selected argument, with its source
identities in [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json). The original
research package also contains a broader action-cover audit, outside this intake.

The original broad package's convenience replay command had a directory-layout
defect, repaired by an additive adapter without changing its frozen bytes.
An earlier separate checker version had an inverse-convention error; its failure
report survives but its source bytes were not retained. Neither failed checker
nor defective entry point is used here. This release replays the retained
standalone mathematical review script, pinned by SHA-256, through the new public
wrapper. This is not a claim that those earlier failures can be reproduced.

Fresh finite controls are secondary evidence, not independent human review.
The private source acceptance records a passing general research audit; the
public release independently runs its own current contract. That acceptance's
historical-manuscript release block is not waived: no historical manuscript is
used as a current publication source.
