Odd-cycle-free
Latin squares

A Latin square is a table in which every symbol appears once in each row and column.

Which sizes admit such tables when comparing any two distinct rows, columns or symbols gives only even-length cycles?

Follow the same symbol.

How does a cycle appear?

Compare the two highlighted rows. Match each symbol in row 0 with the same symbol in row 1, keeping track of the column labels.

  1. In row 0, column 0 contains symbol 0. Row 1 has that symbol in column 1: 0 → 1.
  2. In row 0, column 1 contains symbol 1. Row 1 has that symbol in column 0: 1 → 0.

0 → 1 → 0

The return takes two steps: an even cycle. The other column labels form three more two-step cycles.

An odd cycle in any row pair makes the row view T; no odd cycle in any row pair makes it F. The column and symbol views are checked separately.

FFF requires all three views to pass. One highlighted pair is only an illustration, not the full check.

What changes with an odd cycle?

Apply the same rule to rows 0 and 1 of this smaller table. Symbol 0 sends column 0 to 2; symbol 2 sends 2 to 1; symbol 1 sends 1 back to 0.

0 → 2 → 1 → 0

Three steps is odd, so this row pair already rules out FFF. The complete checker finds an odd cycle in every view: pattern TTT, FFF=False.

Explicit counterexample

Order 12: beyond powers of two

Order 12 admits an explicit FFF square, disproving the former power-of-two conjecture C38, an earlier working conjecture of this project. The shipped order-12, 14, 36 and 98 controls are freshly checked in all three views by two scanning methods.

General constructions beyond powers of two

For every odd integer m > 1, multiplying m by a sufficiently large power of two gives an order with an FFF square. The theorem supplies an upper bound, not the smallest possible exponent or a decision at order 18.

Cross-view triangles and normal forms

For orders n = 2 (mod 4), n at least 6, near-type triangles force an odd companion-view cycle. Each near pair has one 4-cycle and otherwise 2-cycles. The order-18 anchor choices give 31 dual-positive or 13 longest-cycle cases, not solved cases; column positivity is not imposed on the latter.

Structural proofs
Proof + finite controls

Binary two-plex lifts

Component parity exactly characterizes transversal lifts and their count for binary-fibre Latin bases. Standard double prolongation along disjoint transversals with the same projected two-plex is non-FFF. Different-projection pairs are outside this obstruction.

Lift proof & scope

A count is not mate coverage

One fixed FFF16 base has 72,474,624 labelled first transversals / 18,118,656 free-four representatives, not main classes. Only 18 selected supports / 9,216 labelled firsts have arbitrary-mate exclusions; 138,468 liftable supports remain unexcluded by those packages.
