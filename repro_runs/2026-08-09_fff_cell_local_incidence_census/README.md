# 2026-08-09_fff_cell_local_incidence_census

Curated historical source/result export.

See [public reproducibility scope](../../REPRODUCIBILITY.md). This directory is not a freshly rerun or complete historical package. Administrative manifests, personal metadata, environment logs and large external artifacts are deliberately not included. Commands in historical scripts may require other packages or external tools; do not run them in place against frozen results. Use a scratch copy.

The repository-wide `PUBLIC_MANIFEST.sha256` identifies the exported bytes. `PUBLIC_PROJECTION.json` distinguishes unchanged source/result files from privacy-projected records. Historical whole-file hashes in result objects are references to historical bytes, not substitutes for this public manifest.
